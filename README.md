# Squaker 语言

## 概述

Squaker 是一个使用 C++ 实现的轻量级脚本语言，支持动态类型、函数式编程。

## 文档

1. **language_guide.md** - 完整的语言参考，涵盖所有语法和特性

2. **quick_start.md** - 快速上手指南

3. **api_reference.md** - 详细的 API 文档

## 构建

```bash
mkdir build
cd build
cmake ..
cmake --build .
```

启动交互式编辑器：

```bash
./squaker
```
